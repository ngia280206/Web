1. Luồng login JWT và nơi lưu token

Access token ở memory; refresh token ở cookie HttpOnly/SameSite. Server đọc lại user/role/session. 401 hết hạn được refresh một lần theo yêu cầu bổ sung; refresh thất bại về login. Reset không auto-login và thu hồi toàn bộ JWT/refresh cũ.
